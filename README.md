# 等距方块贴纸世界（isometric-block-sticker-world）

把一张参考图（人物、动物、角色、物件、场景或插画）的印象元素提取出来，转译成微缩等距视角（isometric）的可爱方块插画：Q 版 2–3 头身卡通比例、方块圆角体块、剪纸分层与贴纸白边质感。

## 安装

把本仓库作为技能目录克隆（或下载解压）到你环境的 `.user_skills/` 下，保持文件夹名为 `isometric-block-sticker-world`：

```text
workspace/.user_skills/isometric-block-sticker-world/
├── SKILL.md
├── agents/
│   ├── doubao.yaml
│   └── openai.yaml
└── references/
    └── style-dna.md
```

刷新 / 重启技能面板后，即可看到中文名「等距方块贴纸世界」。

## 使用

对话中说「用等距方块贴纸世界帮我画……」，或调用：

```text
$isometric-block-sticker-world
```
