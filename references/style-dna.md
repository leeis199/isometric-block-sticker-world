## 1. 风格锁定轴（不可漂移）

| 轴 | 锁定要求 |
| --- | --- |
| 视角 | 正等距（isometric）三轴 120°，无透视消失点；所有方块顶面 + 两个可见侧面，朝向一致 |
| 造型 | 一切物体方块化、圆角化：主体、建筑、植物、道具都由方盒、圆柱、半圆、台阶等基础体块拼成，边缘圆润 |
| 比例 | Q 版 2–3 头身；头大身小，四肢短粗，五官简化为点线；动物/物件也走同款萌系比例 |
| 材质 | 剪纸 / 贴纸质感：分层纸片、暖白贴纸描边、手工裁切毛边、纸纤维颗粒；扁平色块为主，不做写实 3D 渲染 |
| 色彩 | 从参考图提取 3–5 色为主色板，1 个高饱和点缀色；整体高明度、低对比，奶油/马卡龙倾向，禁止杂色堆砌 |
| 光影 | 柔和顶侧光，纸片下方一层短而淡的软投影；无强烈高光、无镜面反射、无金属铬面 |
| 背景 | 默认纯色或极淡渐变底；用户要求背景设计时，用主色板内的平面图形（色块、波点、条纹、星芒、几何碎纸）铺满背景，不出现纯白底；背景只做承托，不抢主体 |

## 2. 参考图元素提取表

读图后先填这张表，再进入转译。只记录图中可见或可安全推断的信息，不杜撰人物身份、关系、品牌。

- **主锚点**：最强的主体（人物 / 动物 / 物件 / 建筑 / 场景），决定方块世界的中心。
- **支撑物件**：1–3 个与主体相关的小道具、植物、家具、符号，用来填充等距场景。
- **色板**：主色、辅色、底色、点缀色，尽量给色名或近似 hex；颜色必须来自参考图。
- **材质线索**：图中可见的表面质感（布、木、纸、玻璃、毛绒、金属），转译为纸片色块与纹理。
- **氛围**：情绪与季节（温暖 / 清冷 / 热闹 / 安静 / 节日 / 雨天），决定光影与点缀色。
- **小符号**：可重复出现的记忆点（花纹、挂饰、小灯、星星、叶片），用于贴纸化点缀。
- **隐私项**：人脸、文字、招牌、车牌、水印、账号等；按规则裁切、抽象或去除。

## 3. 转译决策规则

- **保留**：主锚点的轮廓特征、标志性配色、关键道具；这些是识别来源的线索。
- **抽象**：复杂背景、纹理细节、次要人物；压缩成大块面与小符号。
- **裁切**：只取局部特写时，保留轮廓与色彩关系，不复刻原图构图。
- **替换**：写实材质替换为纸片色块；尖锐器械、危险物件弱化为圆润图形符号。
- **不照搬**：参考图是印象与配色来源，不是待贴的模板；禁止把原图直接压成封面或背景。
- **人物处理**：需要保留身份时走 Q 版转译；可隐去面部时优先剪影、背影或局部（手、发饰、物件）。不在产品/场景环境中塞入无关人物。

## 4. 等距方块构图规则

### 4.1 两种场景形态

**形态 A · 摆件场景（默认）**：主体站在空基座上，周围散落道具，无墙无家具。

**形态 B · 专属等距房间（dollhouse interior）**：剖切屋顶的方块小屋，主体住在房间里，带地板分区、矮墙与方块家具。用户提到房间、小屋、居室、卧室、客厅、小窝、家具、布置时，采用此形态。

### 4.2 通用构图

- **基座**：场景落在一块方形或圆角方形纸基座上，基座侧面可见厚度；主体居中或略偏一侧，留出对角呼吸位。
- **层级**：按远 → 近叠 2–4 层纸片：远景小块面、中景主体、近景道具；层与层之间留细缝，能看出是分层剪纸。
- **朝向**：所有体块遵循同一等距轴向，不混用正面平视与斜侧视角。
- **间距**：物件之间留宽松间隙，不粘连、不重叠到看不清轮廓；主体最大，家具与道具按 0.5–0.7 倍递减。
- **平衡**：一个视觉重心 + 1–2 个小配重；允许对角不对称，避免左右镜像复制。
- **尺度**：明确微缩感——家具像模型屋配件，主体像小手办；可用极小植物、地毯块、台灯做尺度参照。

### 4.3 房间形态专项规则

- **剖切屋顶**：屋顶完全移除，露出室内；只保留两面或三面矮墙（通常后墙 + 一侧墙），墙高不超过主体坐姿头顶，保证室内全部可见。
- **地板分区**：地板用 1–2 块色块或拼贴纸片区分起居区与家具区，地板边缘与墙根可见厚度。
- **家具清单**：按主体气质选配 2–4 件方块家具（床 / 沙发 / 椅子 / 书桌 / 衣架 / 柜子 / 地毯 / 小台灯 / 绿植），沿墙或角落布置，中央留出主体站立或落座的活动区。
- **家具造型**：家具同样方块圆角化，由方盒、圆柱、半圆拼搭；被褥、坐垫用叠层纸片表示。
- **墙面装饰**：墙面只贴抽象涂鸦线条、小挂饰、色块贴纸等符号；不出现真实文字、海报人物或品牌。
- **动线与遮挡**：家具不穿墙、不悬浮；主体与家具之间留间隙；矮墙不得遮住主体头部与关键特征。
- **氛围匹配**：房间配色与小物件呼应主体气质（酷感少年 → 暗色家具 + 红黑点缀；治愈角色 → 浅色软家具），但仍受第 1 节色板与材质轴约束。
- **人物融入空间**：主体不是僵直站立的手办，姿态要与家具互动——坐床沿、靠书桌、蹲坐地毯、趴扶手、手持小物；重心落在接触面上，肢体有自然弯折。表情生动可读：眯眼笑、挑眉、鼓腮、吐舌、慵懒半垂眼等，配合气质选择；避免千篇一律的正面立正姿势。
- **背景平面设计**：房间外的背景不用白底，铺主色板内的平面图形（同色系波点、斜条纹、几何色块、星芒、碎纸片），图形本身也是带白边的贴纸纸片，疏密有致地围绕小屋分布。

## 5. 剪纸贴纸质感规则

- **描边**：每个纸片外缘一圈暖白（或米白）贴纸边，宽度均匀略不规则，像手工刀模裁切。
- **分层**：主体、道具、背景各自是独立纸片，层间有细缝与淡投影；不要融成一整块平涂。
- **边缘**：纸片边缘带轻微毛边、不齐与纸纤维感；圆角为主，避免锋利矢量直角。
- **纹理**：纸面细颗粒、轻微颜料不均；不做光滑数码矢量、不做水彩湿染。
- **投影**：纸片下方短而软的同色系淡投影，方向统一；无硬阴影、无长投影。
- **点缀**：可加小圆点、短线、星芒、碎纸片等贴纸装饰，但数量克制，围绕主体分布。

## 6. 提示词骨架

编译最终提示词时按以下顺序，写成连贯的中文艺术指导，不要堆逗号关键词：

1. **画幅与视角**：默认 1:1 方图（用户指定 3:4 / 16:9 时跟随），正等距 isometric 微缩场景。
2. **主体转译**：主锚点的 Q 版方块造型、姿态动作（与家具互动的具体姿势）、表情、标志性特征。
3. **场景与道具**：
   - 摆件形态：基座上的分层布置、支撑物件、小符号与尺度参照。
   - 房间形态：剖切屋顶的方块小屋，地板分区、矮墙、2–4 件沿墙布置的方块家具、墙面抽象装饰、中央活动区。
4. **色板**：主色 / 辅色 / 底色 / 点缀色，颜色来自参考图。
5. **剪纸贴纸质感**：分层纸片、暖白贴纸描边、毛边纸纤维、软投影、扁平色块。
6. **氛围与背景**：情绪倾向、柔和顶侧光；背景为配色内平面图形设计或留白底。
7. **负面约束**：见第 8 节。

参考图作为图像输入传入时，明确其角色：只提供印象、配色与轮廓线索，不复刻构图与文字。

## 7. 质检清单

出图后逐项核对：

- [ ] 视角是统一等距，无混乱透视、无消失点
- [ ] 主体 Q 版 2–3 头身，方块圆角造型可读
- [ ] 至少 2 层纸片分层，贴纸白边与淡投影可见
- [ ] 色板 3–5 色，均来自参考图，无杂色堆砌
- [ ] 主体轮廓保留了来源图的识别线索
- [ ] 物件间距宽松，无粘连、无被裁切的关键轮廓
- [ ] 房间形态下：家具沿墙布置、不穿墙不悬浮，中央留出活动区，矮墙不遮主体头部
- [ ] 主体姿态与家具互动、重心落在接触面上，表情生动可读，无僵直立正的手办感
- [ ] 背景为配色内平面图形设计或留白底，无突兀纯白背景
- [ ] 背景纯色承托，无抢戏场景
- [ ] 无乱码文字、无水印账号、无未处理的人脸
- [ ] 整体是扁平剪纸插画，不是写实 3D 渲染或光滑矢量

## 8. 负面约束

避免：写实人像比例、真人皮肤质感、强烈 3D 体积渲染、镜面高光与金属铬面、水彩湿染晕开、纯白或杂乱背景、写实家装效果图与复杂室内透视、僵直站立的手办姿势、无表情正面立正、锐利矢量直角、密集堆砌的道具、左右镜像复制、可辨认的品牌 Logo 与真实文字、乱码字符、水印与截图界面、Q 版之外的猎奇比例、多余人物或手。
